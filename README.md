# Kai Backend

TypeScript + Express + Prisma backend.

## Run

```bash
npm install
cp .env.example .env
npm run dev
```

API: `http://localhost:3000`

Swagger UI: `http://localhost:3000/api/docs`

OpenAPI JSON: `http://localhost:3000/api/openapi.json`

## Commands

```bash
npm run dev
npm run build
npm start
npm run typecheck
npm run lint
npm test
npm run db:generate
npm run db:push
npm run db:migrate
```
